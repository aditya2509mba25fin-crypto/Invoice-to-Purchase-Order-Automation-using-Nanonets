# 🤖 Invoice to Purchase Order Automation using Nanonets

## 📌 Project Overview

This project demonstrates how **Nanonets Intelligent Document Processing (IDP)** can automate the extraction of data from invoices and convert it into structured Purchase Order (PO) information.

The workflow eliminates manual data entry by automatically reading invoice documents, extracting key financial fields, and generating structured outputs for procurement and finance operations.

## 🚀 Process Steps

### Step 1: Upload Invoice
- Upload invoice document to Nanonets.
- Supported formats:
  - PDF
  - JPG
  - PNG

### Step 2: OCR Processing
- Nanonets reads the invoice automatically.
- Text is extracted using OCR technology.

### Step 3: Data Extraction
The system extracts important fields such as:

- Invoice Number
- Invoice Date
- Vendor Name
- Purchase Order Number
- Item Details
- Quantity
- Unit Price
- Total Amount
- Tax Information

### Step 4: Data Validation
- Verify extracted values.
- Correct any extraction errors if required.

### Step 5: Purchase Order Generation
- Extracted data is converted into structured purchase order information.
- Ready for ERP or procurement systems.
